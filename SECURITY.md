# Security Policy

## Reporting a vulnerability

Please report security issues privately to Taha Umar.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/tahachaudhary332-bot/open-library-voxgig-sdk/issues

## Scope

This policy applies to the generated Taha Umar SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Open Library public API, generated by
Taha Umar. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
